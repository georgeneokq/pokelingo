# PokeLingo

ポケモンに触発された日本語学習ゲーム。ジムを探索し、トレーナーやジムリーダーと戦い、日本語の問題に正答することで相手を倒していきます。

## 特徴

- **RPG風のゲームプレイ**: マップを歩き、NPCと交流し、部屋を進んでいく
- **バトルシステム**: 日本語の問題に正答して相手にダメージを与える
- **多様な問題タイプ**: ひらがな、カタカナ、語彙（天気・挨拶・動作）、文作り、助詞
- **コンボシステム**: 連続正答でダメージ倍率が上昇
- **バイリンガル対応**: 設定で英語と日本語（漢字・かな）を切替可能
- **セーブ・ロード**: バトル後に自動セーブ、継続プレイ可能
- **カスタマイズ可能な設定**: 音量・解像度・キー割り当ての変更

## 技術スタック

- **言語:** Java
- **フレームワーク:** LibGDX 1.11.0
- **ビルドツール:** Gradle
- **シリアライザ:** Kryo（セーブデータ用）
- **YAMLパーサー:** SnakeYAML（設定用）
- **テキスト描画:** LibGDX FreeType（日本語文字の動的フォント生成）

## 音声生成

このゲームの音声・問題読み上げはすべて [VOICEVOX](https://voicevox.hiroshiba.jp/) で生成しています。VOICEVOXは日本のオープンソースTTSエンジンです。

## 遊び方（Windows）

遊ぶための最も簡単な方法は、事前にパッケージ化されたリリース版をダウンロードすることです。

### その1：リリース版をダウンロード（おすすめ）

1. **Releases** ページから最新の `pokelingo.zip` をダウンロード
2. zipファイルを任意のフォルダに解凍
3. `run.cmd` をダブルクリックしてゲームを起動

### その2：ソースからビルド

**必要なもの:**
- JDK 17 以降
- `JAVA_HOME` 環境変数がJDKのインストールパスに設定されていること
- Git

**手順:**

1. リポジトリをクローンし、プロジェクトフォルダに移動
2. ビルドスクリプトを実行:
   ```
   python tools/build.py
   ```
3. `dist/` フォルダが作成され、中に `run.cmd` が入っています
4. `run.cmd` をダブルクリックしてゲームを起動

## コントロール

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| インタラクション | Enter |
| ポーズ / メニュー | Escape |
| セーブ | F12 |
| 音声の繰り返し | V |

キー割り当ては設定メニューから変更できます。

## ゲームの流れ

1. メインメニューから**ゲームを始める**を選択
2. **WASD** でキャラクターを動かしてマップを探索
3. NPCに近づいて **Enter** で会話
4. (ジム内で) 会話の後、バトルが開始されます。日本語の問題に正答してダメージを与える
5. 連続正答で**コンボ**を積み、追加ダメージを与える
6. 誤答すると相手がコンボを積む
7. すべてのトレーナーを倒し、**ジムリーダー**に挑戦してゲームをクリア

## 問題タイプ

- **ひらがな**: ひらがなの読み方
- **カタカナ**: カタカナの読み方
- **語彙（天気）**: 天気に関する日本語単語
- **語彙（挨拶）**: よく使う日本語の挨拶
- **語彙（動作）**: 動作の動詞や表現
- **文作り**: 単語を並べて正しい日本語の文を作る
- **助詞**: 正しい助詞（は、が、に、を など）を選択

## 言語サポート

設定で以下の3つの言語モードから選択できます:

- **英語 (EN)**: UIと問題すべて英語
- **日本語 (JP)**: UIと問題を漢字・かなで表示
- **日本語かな (JP_KANA)**: UIと問題をひらがな・カタカナのみで表示

## プロジェクト構造

```
core/           : コアゲームロジック、スクリーン、アクター、出題システム
desktop/        : デスクトップランチャー (LWJGL3)
assets/         : ゲームアセット（マップ、音声、フォント、文字列、会話、問題）
tools/          : 配布パッケージ作成用ビルドスクリプト
docs/           : 開発者向けドキュメント
```

## 開発

### ビルド

```bash
./gradlew desktop:dist
```

`desktop/build/libs/desktop-1.0.jar` が生成されます。

### ソースから実行（開発者向け）

```bash
./gradlew desktop:run
```

`JAVA_HOME` が設定されている必要があります。
